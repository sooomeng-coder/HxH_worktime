# 퇴근 요정 — 구현 기획 요약

> 원본 기획: Manyfast 프로젝트 「컴퓨터 화면에 작게 떠 있는 귀여운 퇴근 요정 기반 근무시간·할 일 관리 도구」
> (projectId `ac7d7c03-2ba8-4018-ac95-d21e818ba9ad`). 기획이 바뀌면 Manyfast가 기준이며 이 문서를 갱신한다.

## 한 줄 정의
컴퓨터 화면에 작게 떠 있는 귀여운 퇴근 요정이 퇴근 예정 시각을 알려주고, 오늘의 할 일을 가볍게 확인해 주는 데스크톱 위젯.

## MVP 범위 결정
- **기기**: Desktop(Windows/macOS)만. Web/Mobile은 제외.
- **로그인·관리자 없음**: 모든 데이터는 사용자 PC의 `state.json` 한 파일에만 저장 (근태 감시 오해 방지).
- **캐릭터 화면은 단순하게**: 남은 시간만 표시. 근무 유형·시작 시각·할 일은 요정 위 ⚙ 설정 버튼에서만.

## 확정된 규칙
| 항목 | 값 |
|---|---|
| 일반근무 | 9시간 |
| 반차 | 4시간 |
| 유연근무 | 기본 8시간 30분, 사용자가 변경 가능 |
| 기본 시작 시각 | 오늘 부팅했으면 부팅 시각, 아니면 앱 실행 시각 |
| 시작 시각 보정 | 부팅 시각 / 부팅 10분 후 / 직접 입력. 현재 이후 시각은 거부 |
| 할 일 개수 | 제한 없음 |
| 할 일 확인 말풍선 | 미완료 할 일 중 무작위 1개. 빈도 끄기/낮음(120~180분)/보통(90~120분)/높음(60~90분) 사이 무작위 간격 |
| 말풍선 응답 | 완료 / 나중에 / 숨기기(완료 아님, 이후 다시 후보) / 오늘 알림 끄기 |
| 다음 근무일의 미완료 할 일 | 새 목록으로 이월할지 물어봄 |
| 퇴근 알림 | 퇴근 예정 시각에 1회. 타이머 종료 / 추가 근무 / 숨기기 |
| 추가 근무 후 재알림 | 30분 후 |
| 전체 화면 앱 사용 중 | 요정 자동 숨김 |
| 시스템 시간 변경 감지 | 재계산할지 사용자에게 확인 |
| 요정 캐릭터 | 흰 둥근 얼굴·검은 귀·날개·하늘색 멜빵바지. 이마 LCD에 남은 시간 → 지나면 `+초과시간`(깜빡임) → 종료하면 `BYE` |
| 마우스 반응 | 눈이 포인터를 바라보고 가까이 오면 살짝 커짐. 클릭·입력은 가로채지 않음 |
