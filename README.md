# 끄적

할 일, 아이디어, 메모를 **한곳에 빠르게 던져두는** PC 위젯이에요.
노션처럼 구조를 고민할 필요 없이, 단축키로 열고 바로 쓰고 Enter로 끝내면 돼요.

## 실행

[Node.js](https://nodejs.org) (LTS)가 설치되어 있어야 해요.

```bash
npm install
npm start
```

화면 오른쪽 위에 작은 위젯이 뜨고, 작업 표시줄 트레이(시계 옆)에 노란 메모지 아이콘이 생겨요.

## 사용법

| 동작 | 방법 |
|---|---|
| 어디서든 위젯 열기/숨기기 | `Ctrl + Shift + Space` (Mac은 `Cmd + Shift + Space`) |
| 끄적이기 | 입력하고 `Enter` |
| 종류 바꾸기 (메모 → 할 일 → 아이디어) | `Tab` 또는 입력칸 왼쪽 버튼 클릭 |
| 종류를 바로 지정해서 쓰기 | `/t 장보기`(할 일), `/i 앱 아이디어`(아이디어), `/m 메모` |
| 수정 | 글자를 더블클릭 → `Enter` 저장, `Esc` 취소 |
| 다시 분류하기 / 삭제 | 항목에 마우스를 올리면 나오는 버튼 |
| 삭제 되돌리기 | 알림의 "되돌리기" 또는 `Ctrl + Z` |
| 위젯 숨기기 | `Esc` 또는 ✕ |
| 항상 위에 표시 켜고 끄기 | 📌 버튼 |

트레이 아이콘을 우클릭하면 **컴퓨터 켜면 자동 실행**과 **종료** 메뉴가 있어요.

### 추천하는 사용 흐름
1. 생각나면 일단 메모로 던져요. 분류는 신경 쓰지 않아도 돼요.
2. 일주일에 한 번 "메모" 탭을 열고 항목을 할 일이나 아이디어로 옮기거나 지워요.
3. 할 일을 끝내면 체크하고, "완료한 할 일 지우기"로 정리해요.

## 데이터 위치

모든 내용은 내 컴퓨터의 JSON 파일 하나에 저장돼요. 인터넷에는 올라가지 않아요.

- Windows: `%APPDATA%\kkeujeok\notes.json`
- macOS: `~/Library/Application Support/kkeujeok/notes.json`
- Linux: `~/.config/kkeujeok/notes.json`

## 구조

```
main.js            창, 트레이, 전역 단축키, 파일 저장
preload.js         화면과 메인 프로세스를 잇는 안전한 통로
renderer/          위젯 화면 (HTML/CSS/JS)
assets/icon.png    트레이 아이콘
```
