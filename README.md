# 퇴근 요정 (HxH_worktime)

화면 구석에 작게 떠 있는 요정이 오늘의 퇴근 예정 시각을 알려주는 데스크톱 위젯입니다.

```bash
npm install
npm start   # 앱 실행
npm test    # 계산 로직 테스트
```

## 사용법

### 요정
- 화면 구석에 떠 있고, 다른 창을 쓰는 데 방해하지 않습니다(포커스를 뺏지 않고, 요정 바깥 투명 영역은 클릭이 통과).
- **이마 화면**: 퇴근까지 남은 시간 → 퇴근 시각이 지나면 `+초과 시간`(깜빡임) → 타이머를 종료하면 `BYE`.
- **드래그**: 위치 이동(다음에 켜도 그 자리). **클릭**: 퇴근 예정 시각·근무 유형·할 일 완료 수 말풍선.
- 눈이 마우스 포인터를 따라봅니다(설정에서 끌 수 있음).
- 마우스를 올리면 **+**(할 일 추가)와 **⚙**(설정) 버튼이 보입니다.

### 퇴근 시각 계산 (개인 참고용)
- 근무 유형: 일반 9시간 / 반차 4시간 / 유연근무(기본 8시간 30분, 변경 가능).
- 시작 시각: 오늘 컴퓨터를 켠 시각(앱을 나중에 켰으면 앱 실행 시각). 설정에서 부팅 시각 / 부팅 10분 후 / 직접 입력으로 바꿀 수 있습니다.
- 퇴근 시각이 되면 말풍선: **퇴근하기**(타이머 종료) / **30분 더**(30분 뒤 다시 알림) / **숨기기**.
- 컴퓨터를 켜 둔 채 날짜가 바뀌면 새 근무일로 넘어가고, 키보드·마우스를 다시 쓰기 시작할 때 타이머가 켜집니다.
- 컴퓨터 시계가 바뀌면 퇴근 시각을 다시 계산할지 물어봅니다.

### 오늘의 할 일
- 요정의 **+** 버튼 → 입력칸에 적고 Enter(계속 입력 가능, Esc로 닫기). 설정 창 체크리스트에서도 추가·완료·삭제할 수 있습니다.
- 가끔 미완료 할 일 하나를 골라 "이 일은 했나요?" 하고 물어봅니다: **완료** / **나중에**(30분 뒤) / **숨기기** / **오늘 끄기**. 빈도는 끄기·가끔(2~3시간)·보통(1.5~2시간)·자주(1~1.5시간).
- 다음 근무일에 못 끝낸 할 일이 있으면 가져올지 물어봅니다.

### 설정 (⚙)
- 반차·유연근무 체크(둘 다 해제하면 일반근무), 업무 시작 시각 수정, 체크리스트.
- **위젯 설정**(접었다 펴기): 크기 70~150%, 투명도 30~100%(마우스를 올리면 선명), 할 일 확인 빈도, 마우스 따라 쳐다보기, 요정 숨기기, 컴퓨터 켤 때 자동 실행.
- 요정 숨기기/보이기 단축키: Windows `Ctrl+Alt+H`, Mac `⌘+⌥+H`. 트레이(메뉴 막대) 아이콘 메뉴에서도 숨기기·설정·종료.

### 데이터
- 로그인·서버 없음. 모든 데이터는 내 컴퓨터의 `state.json` 파일 하나에만 저장됩니다.

## 설치 파일 만들기

- **GitHub에서 (추천)**: 저장소 → Actions → "설치 파일 만들기" → Run workflow. 끝나면 Artifacts에서 Windows(`.exe`)·Mac(`.dmg`, Apple 실리콘 M칩용, macOS 12 이상) 설치 파일을 받습니다.
- **내 PC에서**: Windows는 `npm run dist:win`, Mac은 `npm run dist:mac` → `dist/` 폴더에 생성.
- 코드 서명을 하지 않아서 처음 실행할 때 Windows는 "PC 보호" 창에서 **추가 정보 → 실행**, Mac은 앱을 응용 프로그램 폴더로 옮긴 뒤 터미널에서 `xattr -dr com.apple.quarantine "/Applications/퇴근 요정.app"`을 한 번 실행해야 합니다(또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**).

기획과 진행 상황은 [docs/plan.md](docs/plan.md)에 있습니다.
